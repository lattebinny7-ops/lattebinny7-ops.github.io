개인정보처리방침

검토용 초안 · 현재 홈페이지와 학교용 타이머를 기준으로 작성했습니다. Google OAuth 연동 앱의 정책으로 사용하기 전에는 실제 앱의 정보 처리 내용과 문의 연락처를 확정해야 합니다.

작성일: 2026년 11월 4일 · 운영자: lattebinny7-ops

1. 적용 범위

이 문서는 대표 홈페이지와 학교용 타이머의 현재 기능에 대한 개인정보 처리 안내입니다. 별도의 Google 연동 앱에는 자동으로 적용되지 않습니다.

2. 앱에서 처리하는 정보

현재 홈페이지와 타이머에는 회원가입, 로그인, 이름·이메일 입력, 자체 분석 도구가 없습니다. 타이머의 설정과 남은 시간은 브라우저 메모리에서 처리되며, 앱 코드는 이를 운영자 서버로 전송하거나 쿠키·로컬 저장소에 저장하지 않습니다. 새로고침하거나 페이지를 닫으면 현재 타이머 상태가 사라집니다.

3. 호스팅과 외부 서비스

페이지는 GitHub Pages에서 제공됩니다. 접속 과정에서 GitHub가 IP 주소 등의 기술 정보를 처리할 수 있으며, 자세한 사항은 GitHub 개인정보처리방침을 참고하세요.

타이머 알람 재생 시 브라우저가 soundbible.com의 음원 파일을 요청합니다. 이 과정에서 IP 주소, 브라우저 정보 등의 요청 정보가 해당 제공자에게 전달될 수 있습니다. 외부 음원 제공자의 정보 보관 기간은 운영자가 관리하지 않습니다.

4. Google 계정 정보

현재 확인된 서비스는 Google OAuth를 사용하지 않으며 Google 계정 정보, Drive 파일, Calendar 일정에 접근하지 않습니다. Google 연동 기능을 추가할 경우 요청 권한, 이용 목적, 저장 위치, 보관 기간, 공유 대상, 삭제 및 연결 해제 방법을 실제 구현에 맞게 안내해야 합니다.

5. 문의와 삭제 요청

현재 앱 자체에는 사용자 계정이나 서버에 보관하는 타이머 기록이 없습니다. 일반 기능 문의는 GitHub Issues에서 할 수 있습니다. 공개 게시물에 이메일, 비밀번호 등 개인정보를 올리지 마세요. 개인정보 관련 비공개 문의 연락처는 운영자 확인 후 게시할 예정입니다.

6. 변경 안내

기능이나 정보 처리 방식이 변경되면 이 페이지의 내용과 날짜를 수정합니다. 본 초안은 운영자의 검토와 실제 배포 후 확정됩니다.
